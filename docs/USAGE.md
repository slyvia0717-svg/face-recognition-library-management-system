# 使用说明

## 借阅者

注册成功后先使用密码登录。个人中心可分别修改昵称、姓名和电话；改昵称后使用新昵称登录，记录仍属于同一个账号。

人脸设置需输入当前密码并正对摄像头拍摄，保持画面只有一张清晰人脸。可重新录入或删除。登录页先填昵称，再拍摄并确认人脸验证。摄像头不可用或验证失败时使用密码登录。

借书时可先搜索书名或编号，再扫描对应图书。扫描后核对书名和库存，点击确认借阅。超时后可重试，前端保留操作编号，后端避免重复扣库存。归还页只显示个人待还图书；旧账待核对记录需管理员确认关联。

测试时无需实体书：在另一台设备上展示“查看测试二维码”下载的码。手动输入 `LIB000001` 等演示编号也可体验相同查书流程。

## 管理员

使用本机 `npm run set-password -- admin` 设置管理员密码，无默认密码。图书页可添加和修改馆藏、数量与编号。新图书库存等于总数，后续库存由借阅占用自动计算。编号应与实际扫描内容一致，保存为文本，保留前导零。

人员页维护账户资料；借阅记录页可选择固定用户、图书、状态和合法日期，库存随记录修改同步更新。统计页按 YYYYMMDD 日期查询当天借出与归还数量。

## 常见情况

- 摄像头拒绝：在浏览器中允许访问；使用 localhost 或 HTTPS，普通局域网 HTTP 地址可能无法使用。
- 未检测到人脸：改善光线、正对镜头并靠近摄像头，重新拍摄。
- 识别忙或模型异常：稍后重试，或者继续密码登录。
- 未知图书码：由管理员将实际条码录入对应图书；数据库不会自动联网查询 ISBN。
- 无库存：该书无法新借阅；归还或增加馆藏后再次查询。
- 密码恢复：维护者在本机运行 set-password；该账号会话及人脸凭据同时撤销，之后需重新录入。

页面顶部提供退出登录，底部共享导航提供图书、记录和个人中心等入口。
